# brain/ — the long memory of the Թագաւորութիւն

Strategy, decisions-and-why, playbooks, postmortems. Charter lifetime is
months-to-years; content is pulled on demand, not auto-loaded. (System
documentation belongs in `docs/` and `CONTEXT.md`; procedures for the repo's
*code* belong there too. This directory is about how the *society* runs.)

- `playbooks/` — standing procedures: the citizen protocol, the design-gate,
  handoffs, mail etiquette. A citizen who wonders "how do we do X here" looks
  here first.
- `decisions/` — numbered decisions-and-why for the kingdom itself, in the
  spirit of `docs/adr/` but scoped to the society. Write one when a rule is
  made or changed; say why, and what was rejected.
- `postmortems/` — blameless, per Constitution Article III.4. One file per
  incident, named `YYYY-MM-DD-<slug>.md`: what happened, why, what changed.

Any citizen may add or amend files here by PR, same as code.
